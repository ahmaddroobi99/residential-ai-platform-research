# 07 · Archistar

**Slice:** zoning-aware generative massing  
**Site:** [archistar.ai](https://www.archistar.ai/)  
**HQ:** Sydney. Also ships as a Forma add-on (2025+).

## What it does

Planning rules + site → compliant design options. Used by developers and some governments in AU; Forma add-on opened a global AECO path.

## Product still

![Archistar lot-by-lot housing layout](images/archistar-lots.jpg)

Stage lots, setbacks, generated house models. Source: Archistar blog.

## Fits our map

- Zoning / setbacks / height
- Site packing for production housing
- Massing into Forma → Revit

## Limits

Not interior furniture / FF&E. Not a twin. Planning data quality is jurisdiction-specific — Metro Vancouver / Surrey must be verified separately (LTSA).
