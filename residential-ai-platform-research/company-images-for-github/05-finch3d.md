# 05 · Finch 3D

**Slice:** generative housing floor plans from a massing  
**Site:** [finch3d.com](https://www.finch3d.com/)  
**HQ:** Malmö / Stockholm. Rhino + Revit plugin + web.

## What it does

Graph-based generation of multi-family floor plans. Live metrics (area, daylight, circulation, CO2e). Architect stays in the massing; Finch fills storeys.
