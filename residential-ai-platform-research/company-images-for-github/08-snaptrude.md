# 08 · Snaptrude

**Slice:** browser conceptual BIM  
**Site:** [snaptrude.com](https://www.snaptrude.com/)

## What it does

Program table → massing → presentation decks in the browser. Claims text / RFP → LOD 300-ish model with Revit export. Snap AI sits next to the model.
